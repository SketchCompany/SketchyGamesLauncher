# Sketchy Games Launcher

The Sketchy Games Launcher is a software, which hosts all games and softwares provided by the Sketch Company. 
You can download, manage and play every game or software easily. It also features managing your account, chatting and playing with friends.
In the future, you will be also able to mod your games.
The launcher updates itself automatically and manages to update your games.

[!NOTICE]
Currently the launcher is not available for copying the code and contents for modding, addons, plugins or any other changes.

## Download
The Launcher can be downloaded here: https://sketch-company.de/launcher/downloads
